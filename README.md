# turtton/tap

Homebrew tap for [cnowledje](https://github.com/turtton/cnowledje) — a read-only Confluence and Jira CLI for Server/Data Center.

## Installation

```sh
brew tap turtton/tap
brew install cnowledje
```

## Usage

```sh
cnowledje --help
```

## Documentation

See the [cnowledje README](https://github.com/turtton/cnowledje) for full usage instructions.
